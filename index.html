FAQ

常見問題Questions people ask

Panlo 跟一般的檔案管理或雲端硬碟差在哪？How is this different from a file manager or cloud drive?
雲端硬碟幫你「存」檔案，Panlo 幫你「用」檔案。它會把文件內容建立語意索引，所以你可以用平常的話問問題、要它跨檔案比對、產出報表。再往下一層，你可以把常做的事存成技能、設成定時觸發，或做成同事都能用的小應用 — 這部分是檔案管理工具沒有的。 A cloud drive stores files. Panlo uses them. It builds a semantic index of the content, so you can ask questions in plain language, compare across documents and produce reports. Beyond that you can save what you do repeatedly as a Skill, schedule it as a Trigger, or wrap it in an App your colleagues can run — none of which a file manager does.
「技能」和直接打一段提示詞有什麼不同？What's the difference between a Skill and just typing a prompt?
提示詞是一次性的，下次要重打，而且每個人打得不一樣，結果也不一樣。技能有名字、有觸發字、有固定步驟，可以指定要用哪些工具和哪個範本檔。存好之後分享給同事，他們只要說一句話就能跑出同樣格式的結果，不需要知道裡面寫了什麼。 A prompt is one-off — you retype it next time, everyone words it differently, and the results differ. A Skill has a name, trigger words and fixed steps, and can pin the tools and template files it uses. Share it and a colleague runs it with one sentence, getting the same format every time, without needing to know what's inside.
支援哪些檔案格式？Which file formats are supported?
20 種以上：文件（PDF、DOC、DOCX、TXT、RTF）、試算表（XLS、XLSX、CSV）、簡報（PPT、PPTX）、圖片（JPEG、PNG、GIF、WEBP）、音訊（MP3、WAV、M4A、FLAC、AAC）、影片（MP4、MOV、AVI、MKV）、電子郵件（EML、MSG）以及常見程式碼檔。音訊與影片會自動轉錄成文字後一併建立索引。 More than 20: documents (PDF, DOC, DOCX, TXT, RTF), spreadsheets (XLS, XLSX, CSV), presentations (PPT, PPTX), images (JPEG, PNG, GIF, WEBP), audio (MP3, WAV, M4A, FLAC, AAC), video (MP4, MOV, AVI, MKV), email (EML, MSG) and common code files. Audio and video are transcribed and indexed alongside the rest.
觸發會不會自己亂寄信？Can a trigger send email on its own without me knowing?
每個觸發你都可以選兩種模式其中一種：「自動執行」直接完成，「草稿待審」會把東西準備好、停在那裡等你確認。另外，寄信、刪除檔案、更動行事曆這類會影響外部的動作，預設都會先詢問。 Each trigger runs in one of two modes: auto-approve, which completes on its own, or draft-and-hold, which prepares the work and waits for you. Separately, actions that reach outside the app — sending mail, deleting files, changing a calendar — confirm with you by default.
